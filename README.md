# Echoes of the Sunken Spire

**Echoes of the Sunken Spire** is a 3D platforming and environmental puzzle game developed using Unity.

The project focuses on combining platforming mechanics, environmental interaction, puzzle solving, and light-based gameplay within a mysterious underwater structure.

## Project Overview

The game takes place inside a forgotten underwater temple and mechanical tower known as the **Sunken Spire**.

The player controls a lone character attempting to ascend through the structure. Progression requires navigating platforms, avoiding environmental hazards, solving puzzles, and discovering paths hidden throughout the environment.

A central element of the game is the interaction between **light and the environment**. The player uses a lantern and other light sources to interact with objects, reveal hidden passages, and solve environmental puzzles.

## Game Genre

- 3D Platformer
- Puzzle
- Environmental Action
- Exploration

## Core Gameplay

The gameplay is based on exploration and progression through different sections of the Sunken Spire.

The main gameplay elements include:

- **3D Platforming:** Navigating platforms and vertical sections of the environment.
- **Environmental Puzzles:** Solving puzzles by observing and interacting with surrounding objects.
- **Light-Based Interaction:** Using light sources to manipulate or reveal elements of the environment.
- **Hidden Paths:** Discovering passages and alternative routes through environmental clues.
- **Environmental Hazards:** Avoiding obstacles and dangerous areas while progressing through the level.
- **Timed Challenges:** Completing certain sections or interactions within a limited amount of time.
- **Exploration:** Investigating the environment and discovering different areas of the structure.

## Main Objective

The primary objective of the player is to reach the upper sections of the Sunken Spire.

To progress, the player must combine movement, observation, environmental interaction, and puzzle-solving skills. Each section of the structure introduces obstacles and environmental challenges that must be overcome to continue the ascent.

## Running the Project

To run the project:

1. Clone or download the repository.
2. Open **Unity Hub**.
3. Select **Add project from disk**.
4. Select the project directory.
5. Open the project using **Unity 6.3 LTS (6000.3.4f1)**.
6. Open `Assets/_Project/Scenes/Main.unity`.
7. Enter **Play Mode** in the Unity Editor.
